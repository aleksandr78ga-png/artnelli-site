# Архив Art Nelli OS

Архив хранит устаревшие, замененные или временно неиспользуемые материалы, которые нельзя без необходимости уничтожать.

Правила:
- перенос в архив предпочтительнее удаления;
- сохраняется причина архивации и дата;
- секреты и персональные данные в архив не помещаются;
- окончательное удаление требует подтверждения Нелли;
- для восстановления материала используется история GitHub и описание контекста.
