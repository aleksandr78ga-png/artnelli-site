2. Какие данные обрабатываются

При отправке заявки пользователь может передать имя, номер телефона или контакт в мессенджере, город, рост спортсменки, желаемый срок, сведения о выступлении и пожелания к изделию. При запуске внутри MAX сервис также передаёт технические данные сессии и идентификатор пользователя, необходимые для безопасной отправки заявки.

3. Цель обработки

Данные используются только для ответа на заявку, уточнения модели, цены, наличия, сроков пошива и доставки, а также для защиты формы от поддельных запросов.

4. Основание

Обработка выполняется с согласия пользователя, которое он подтверждает перед отправкой формы, и для действий по запросу пользователя до заключения договора.

5. Передача и хранение

Заявка передаётся мастерской Art Nelli через официальный API бота MAX. Если прямая отправка ещё не подключена, пользователь сам выбирает чат для отправки сформированного текста. Данные не продаются и не используются для массовой рекламной рассылки.

6. Срок хранения

Данные хранятся не дольше, чем это необходимо для ответа, оформления и исполнения заказа, выполнения требований законодательства и разрешения возможных споров.

8. Безопасность

Передача выполняется по HTTPS. Секретный токен бота не хранится в открытых файлах сайта и используется только на серверной стороне. Данные запуска MAX проверяются криптографической подписью перед прямой отправкой заявки.
