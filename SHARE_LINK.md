# Ссылка без фотографий для публикаций

По поручению Нелли от 28 сентября 2026 подготовлена ссылка:
`https://artnelli.com/go/`.

Статическая страница `site/go/index.html` возвращает HTML без фотографий,
видео, Open Graph, Twitter Cards, описания и canonical на главную. Пустая
иконка задана через data URI, чтобы не запрашивать изображение favicon.
Для поисковых роботов заданы noindex, nosnippet и noimageindex.

В браузере JavaScript сразу открывает главную страницу на том же домене
через `location.replace`, сохраняя параметры и якорь. Если JavaScript
недоступен, остаётся обычная текстовая ссылка «Открыть artnelli.com».
HTTP-редирект и meta refresh намеренно не используются: роботы превью
могут перейти по ним к главной и взять её фотографии.

Сама главная и её фотографии не изменены. Не добавлять фотографии, OG,
Twitter Cards или ссылки на изображения в страницу `/go/`.

Ограничение: соцсеть сама решает, создавать ли карточку, исполнять ли
JavaScript, следовать ли ссылкам и использовать ли старый кеш. Ни этот URL,
ни метатеги не могут запретить любые превью на всех площадках. Для строго
текстовой публикации нужно отключать превью в редакторе конкретной соцсети.
Этот адрес использует обычный HTTPS и не требует VPN; доступность сайта
через каждого провайдера, из каждой страны или через любой VPN не гарантируется.
