# PROJECT_CONTEXT.md — artnelli.com

## Тип
Основной публичный сайт Leotards by Nelli.

## Назначение
Представление бренда, запись на пошив, инструкция по снятию мерок, каталог новых и б/у купальников в наличии.

## Текущий статус
Опубликован и работает.

## Ответственные агенты
- Илон — техническая часть.
- Генри — синхронизация карточек и материалов.
- Марк — тексты и продвижение.
- Лео — визуальные материалы.

## Источники данных
- GitHub-репозиторий;
- Telegram-канал каталога;
- утвержденные материалы Нелли.

## Особое правило
Работающий сайт нельзя визуально или функционально менять при реорганизации файлов без отдельного подтверждения Нелли.

## Автоматизация
Синхронизация Telegram-каталога является ранее согласованным процессом. Изменение логики синхронизации требует отдельного подтверждения.

## Подготовка подключения VK — 2026-09-29

По поручению Нелли «Сделай» подготовлена YML-выгрузка общего каталога:
`/feeds/vk.yml`, с отчётом `/feeds/vk-report.json`. Обновляется при публикации
каталога. Принимающая интеграция VK ещё не подключена: наличие файла по ссылке
не подтверждает автоматическое обновление магазина. Существующие карточки VK
не изменены. Требования, ограничения цен/изображений и порядок сопоставления
карточек записаны в [VK_SYNC.md](../../VK_SYNC.md).
