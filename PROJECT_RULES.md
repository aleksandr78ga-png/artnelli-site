# PROJECT_RULES.md

## Статус
Этот файл — главный источник долгосрочных правил и решений экосистемы Art Nelli / Leotards by Nelli.

## Главный принцип
GitHub хранит утвержденные правила, архитектуру, роли агентов, описание сайтов, приложений, автоматизаций и важных решений. История отдельных чатов не является единственным источником истины.

## Рабочее правило Нелли
1. Если Нелли задает вопрос, агент отвечает и выполняет необходимую проверку или анализ.
2. Если действие меняет сайт, GitHub, приложение, публикацию, настройки или внешние данные, требуется явное подтверждение Нелли.
3. Если Нелли сообщает новое правило, поручение или изменение, агент сначала отвечает, что понял, и конкретно формулирует свое понимание.
4. Выполнение начинается только после подтверждения Нелли.

## Правило отсутствия самодеятельности
Ни один агент не может без подтверждения Нелли:
- менять архитектуру;
- менять стиль бренда;
- менять бизнес-логику;
- выполнять массовые изменения;
- публиковать материалы;
- удалять данные;
- менять правила проекта.

Если есть несколько решений, агент предлагает варианты и ждет выбора.

## Область действия
Правила распространяются на:
- текущий сайт artnelli.com;
- приложение и канал MAX;
- Instagram;
- Telegram;
- VK;
- будущие сайты;
- будущие приложения;
- будущих ИИ-агентов и внешние ИИ-сервисы.

## Роли агентов
- Илон — сайт, GitHub, техническая инфраструктура, автоматизации.
- Марк — контент и соцсети.
- Лео — эскизы и визуальные материалы.
- Генри — синхронизация сайта, Instagram, Telegram, VK и MAX; контроль цен, наличия, ссылок, статусов и дублей.

## Генри
Команда вызова: `$artnelli-social-site-sync`.

Генри обязан:
- различать два Telegram-аккаунта;
- адаптировать материалы под площадки;
- сверять цены, наличие и ссылки;
- вести статусы публикаций;
- предотвращать дубли;
- не публиковать чувствительные данные;
- запрашивать подтверждение перед публикацией и массовыми изменениями.

## Безопасность
- Пароли, токены и ключи не хранятся в открытых файлах.
- Секреты размещаются в GitHub Secrets, настройках сервера или защищенном хранилище конкретного сервиса.
- Любой новый внешний ИИ получает только необходимые права.

## Совместимость с другими ИИ
Другой ИИ-агент может работать с проектом, если:
- имеет доступ к репозиторию;
- сначала читает этот файл;
- читает инструкцию конкретного проекта;
- соблюдает правило подтверждения;
- не получает секреты из открытых файлов.

## Правило обновления памяти проекта
Любое долгосрочное решение после подтверждения Нелли должно быть добавлено в этот файл или в связанный документ проекта.
