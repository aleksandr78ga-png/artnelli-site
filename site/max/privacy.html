2. Какие данные обрабатываются

Мини‑приложение не запрашивает и не отправляет мастерской через форму имя, номер телефона, город, мерки спортсменки или другие персональные данные. Для записи пользователь выбирает желаемый месяц или слот и подтверждает ознакомление с условиями оплаты работы над эскизами. Для обращения по готовому изделию приложение формирует название модели, рост и ссылку на её карточку. Сформированный текст копируется на устройство пользователя.

Платформа MAX может обрабатывать технические данные, необходимые для запуска мини‑приложения, в соответствии со своими документами. Мини‑приложение не использует эти данные для автоматической отправки заявки мастерской.

3. Цель обработки

Выбранный слот, подтверждение условий и сведения о выбранной модели используются только для подготовки обращения к Нелли в личном MAX. Остальные детали заказа обсуждаются уже в личной переписке.

4. Основание

Личная переписка начинается только после того, как пользователь сам переходит в профиль Нелли и отправляет сообщение. Дальнейшая обработка выполняется для ответа на обращение и действий по запросу пользователя до заключения договора.

5. Передача и хранение

Мини‑приложение не отправляет текст обращения на сайт, сервер мастерской или через API бота автоматически. Текст попадает Нелли только после того, как пользователь вставит и отправит его в личной переписке MAX. Данные не продаются и не используются для массовой рекламной рассылки.

6. Срок хранения

Сайт не хранит данные формы записи. Сообщения, которые пользователь самостоятельно отправляет в MAX, могут храниться в переписке не дольше, чем это необходимо для ответа, оформления и исполнения заказа, выполнения требований законодательства и разрешения возможных споров.

8. Безопасность

Страницы мини‑приложения передаются по HTTPS. В форме записи нет полей для имени, телефона или других персональных данных, а её содержимое не отправляется на сервер мастерской.

9. Обновления

Политика может обновляться при изменении функций приложения или требований закона. Актуальная версия всегда доступна по этой ссылке.
